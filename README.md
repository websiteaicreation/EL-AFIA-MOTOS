# EL AFIA MOTOS

Premium motorcycle and scooter rental website for EL AFIA MOTOS, Tetouan, Morocco.

- French, English, and Arabic
- Fleet: Capochino, Swing, Sania, Daytona
- General rates: 150 DH / day, 900 DH / week, 3,500 DH / month
- Bookings open WhatsApp (`+212 604 598 662`) and are confirmed by the agency

## Run

```bash
npm install
npm run dev
```

Prices live in `src/lib/fleet.ts`.
